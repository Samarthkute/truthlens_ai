TRUTHLENS AI — FRONTEND STARTER
================================

HOW TO RUN
1. Extract TruthLens_AI.zip.
2. Open the extracted folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

INCLUDED
- Login and sign-up demo screens
- Responsive dashboard inspired by a polished SaaS/cooperative-platform visual style
- Text, image and link input screens
- Demo review output and printable PDF report (browser Print → Save as PDF)
- Local review history
- Built-in FAQ-style chatbot
- English / Hindi / Marathi selector (key dashboard labels)
- Dark / light theme

IMPORTANT LIMITATIONS
This is a frontend prototype. Login and sign-up are stored locally in the browser and are NOT secure authentication.
The verification result is a simple illustrative heuristic, not an actual trained AI/ML fake-news detector.
Image upload is preview-only; it does not analyse image authenticity.
The chatbot uses prepared responses and is not connected to a live LLM.
The language selector translates selected interface labels only, not every page or generated result.

FOR A REAL PROJECT
Connect a backend authentication service, a trained text classification model, trusted fact-check/source APIs, image-analysis service, real multilingual translations, and a server-side report generator. Avoid presenting demo scores as factual verdicts.
